# Anireil Rules

Официальный сайт правил сообщества Anireil.

Сайт содержит три документа:

- Конституцию Anireil;
- Кодекс Anireil;
- Индекс запретов Anireil.

Исходные тексты синхронизированы из `anireilst/Anireil-Bot/rules`. Интерфейс сайта не должен изменять смысл, формулировки или санкции документов.

## Структура

- `index.html` — оболочка сайта;
- `styles.css` — адаптивный интерфейс;
- `app.js` — навигация, поиск и отображение документов;
- `data/rules.json` — данные действующей редакции правил.

Сайт рассчитан на GitHub Pages и не требует отдельного backend.
